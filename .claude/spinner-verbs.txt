# .claude/spinner-verbs.txt — the spinner corpus (contracts §12 / R5 SD-3).
#
# One verb per line. Blank lines and lines starting with `#` are ignored.
# `scripts/sync_spinner_verbs.py` materializes this list into
# `.claude/settings.json` → `spinnerVerbs.verbs` (mode: "append", so the
# built-ins survive). `make spinner-check` fails when the two drift.
#
# RULES, and they are load-bearing:
#   * GERUNDS ONLY. Claude Code renders each entry as "<Verb>…" while a turn
#     runs. Since v2.1.144 the past-tense turn-completion line ("Worked for
#     5s") always uses built-ins, so a past-tense entry here is just wrong.
#   * ≤ 16 characters. Narrow terminals wrap, and a wrapped spinner is sad.
#   * These are renamed with everything else at onboarding — a verb may
#     legitimately contain `MyApp` and will come out the other side as your
#     app's name. Exactly one entry below does; mind the length after rename.
#   * Needs Claude Code v2.1.144+. Below that, verbs leak into past tense.
#
# Yes, it is profane. That was the requirement. Cut what you don't want —
# any subset ≥ 1 entry is valid, the schema only demands minItems: 1.
